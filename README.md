# Контур — здоровье

Личное PWA-приложение к контуру здоровья `mihizumov-healthbook`.
Показывает не анализы, а **нагрузку на системы тела** и то, **чего контур не видит**.

⛔ **Не медицинское изделие.** Приложение не ставит диагнозов, не назначает и не
отменяет препараты. Формулировка выхода всегда одна: *вот что видно в данных —
вот вопрос врачу такой-то специальности.*

---

## Четыре раздела

| Раздел | Отвечает на вопрос |
|---|---|
| **Заряд** | Насколько тело под нагрузкой и насколько контур это видит |
| **Системы** | Что под ударом: сердце · почки · печень · ЖКТ · суставы и обмен · мозг |
| **Прогресс** | Воскресные отметки, ряд «Заряда», счётчики гипотез |
| **Данные** | Чего нет: пробелы, просрочки, пробелы на фоне терапии, препараты, диагнозы, задачи |

## «Заряд» — что это и чем не является

Шкала 0–100 по метафоре Garmin Body Battery, но **без непрерывной телеметрии**:
ни сна, ни шагов, ни пульса. Считается из того, что уже записано в мастерах
контура — отклонений от личных целей, направления рядов, симптомов недели и
лекарственной нагрузки.

Веса названы открытым текстом в `src/composables/chargeModel.js`:

```
CVD 10 · KID 9 · LIV 7 · GIT 7 · JNT 7 · NEU 5   = 45  состояние систем
trend    15                                       направление рядов
symptoms 20                                       недельный слой
exposure 10                                       НПВС, алкоголь, курение, пурины
                                            итого 90
```

Четыре правила, без которых балл был бы гаданием:

1. **Веса опубликованы.** Балл, у которого веса не названы, проверить нельзя.
2. **Разбирается на слагаемые в один тап** — экран «Из чего сложился».
3. **Дельта меньше 4 пунктов изменением не считается** — шум шкалы не должен
   читаться как движение.
4. **Рядом всегда стоит полнота данных.** При полноте ниже 65% вместо числа
   показывается диапазон, ниже 30% — прочерк и список того, чего не хватает.
   ⛔ Число в режиме «слепо» не показывается вовсе: один раз увиденное, оно
   дальше живёт само по себе, а оговорка рядом — нет.

## Воскресная отметка

Одиннадцать вопросов в шести шагах: WHO-5 (индекс благополучия ВОЗ), суставы,
ЖКТ, экспозиция, текущие процессы, события. Имена полей — ровно из шаблона
`weekly/weekly_ГГГГ.md`, чтобы экспорт ложился в мастер без перевода.

- Ответы хранятся в `localStorage` телефона — **это не мастер**.
- Кнопка «Экспорт недели» даёт готовый блок для `weekly_2026.md`.
- ⛔ Задним числом отметка не заполняется: доступны текущая неделя и предыдущая
  (до среды). Память подгоняет ответ под гипотезу.
- ⛔ «Ничего не было» — отдельная кнопка. Молчание и «ничего» — разные факты.

## Данные

Приложение — **потребитель**. Оно не разбирает мастера и ничего не считает
заново: всё готовит генератор в репозитории контура.

```bash
# в mihizumov-healthbook
python3 tools/build_app_data.py     # → app/public/data/health.json
```

⛔ `public/data/health.json` руками не править. Правка мастера → генератор →
генерат пересобран.

## Разработка

```bash
npm install
npm run dev        # локальный сервер
npm run build      # сборка в dist/
npm run test       # дымовая проверка: экраны, вход, границы контура
npm run single     # однофайловая сборка dist/preview.html (снимок, без обновления данных)
```

### Смена пароля

```bash
npm run passcode "новая фраза"
# вставить полученный PASSCODE_HASH в src/config.js
```

Логин зафиксирован: `b00mbastic` (как в «Бумбастике»). В проверке он не
участвует — поле показывает контекст входа.

⚠ **Вход — заслон от случайного гостя, а не защита.** Бэкенда нет, проверка
идёт в браузере, данные лежат в репозитории открыто. Это решение владельца от
29.08.2026, и приложение говорит об этом прямо на экране входа. Настоящее
закрытие — это другая архитектура (шифрование файла данных ключом из пароля
либо приватный репозиторий с серверным гейтом), а не более длинный пароль.

## Публикация

GitHub Pages, workflow `.github/workflows/deploy.yml`. Порядок перед каждым пушем:

```bash
python3 tools/build_app_data.py          # в репозитории контура
git -C app add public/data/health.json
git -C app commit -m "данные на <дата>"
git -C app push
```

Workflow падает с внятной ошибкой, если `public/data/health.json` отсутствует:
без него приложение открывается пустым экраном, и причину видно только в консоли.
